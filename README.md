# 🏥 Secure Medical Appointment Booking System

A professional, full-stack medical appointment management application built with **Python**, **Streamlit**, and **SQLite**. This system features secure user authentication and a comprehensive dashboard for managing medical appointments and doctor profiles.

## 🚀 Key Features

* **🔐 Secure Authentication:** Implemented user registration and login using `bcrypt` for secure password hashing.
* **💾 Database Management:** Utilizes `SQLite` for reliable data storage of users and doctor information.
* **👨‍⚕️ Doctor Dashboard (CRUD):** * **Create:** Add new doctors to the system.
    * **Read:** Search and filter doctors by name or specialty.
    * **Update:** Edit existing doctor details, ratings, and images.
* **📅 Appointment Scheduling:** Intuitive booking interface for patients.
* **🎨 Responsive UI:** Built with Streamlit for a clean, user-friendly experience.

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **Backend:** Python
* **Database:** SQLite3
* **Security:** bcrypt (Password Hashing)
* **Data Analysis:** Pandas
